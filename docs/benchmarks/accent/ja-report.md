# L3 アクセント・レポート(ja)

フロントエンドが **実際に decode へ渡している mora 単位の H/L** を一覧する。音素レベルの L3 gate はピッチの誤りを見逃すため(「せんに→ひゃく」の実例、docs/evaluation.md §3.4)、この粒度で測る必要がある。

生成: `cargo run --release --features onnx --example accent_report`
(アノテーション: `tests/evaluation/annotations/ja_accent.jsonl` に `expected_tones` を記入すると、以後は一致チェックになり、CI gate にできる)

## 現状の出力(2026-09-14、母音のトーンを採る実装に修正後)

| 入力 | カナ | tones(H/L) | 期待(要記入) |
|---|---|---|---|
| `1,200` | センニヒャク | `HLLHH` |  |
| `1,200円` | センニヒャクエン | `HLLHHLL` |  |
| `2026年2月14日` | ニセンニジュウロクネンニガツジュウヨッカ | `LHLHLLLHLLLLHHLLLL` |  |
| `午前10時` | ゴゼンジュウジ | `HLLLHL` |  |
| `こんにちは` | コンニチワ | `LHHHH` |  |
| `猫が座って動かない。` | ネコガスワッテウゴカナイ. | `HLLLHHHLHHLLL` |  |
| `ありがとうございました` | アリガトオゴザイマシタ | `LHLLLLHHHLL` |  |

## 読み方と注意

- `tones` は 1 文字 = 1 モーラ、`H`=高 / `L`=低。句読点はトーンを持たないため含まれない
- この H/L は VITS2 decode に渡る**アクセント素性**であり、音響的な F0 そのものではない
- したがって二段構えで見る必要がある:
  1. **素性の誤り**(フロントエンド/アクセント推定の問題)→ このレポートで検出でき、修正は正規化層・辞書・アクセント規則の仕事
  2. **実現の誤り**(素性は正しいが音が平坦)→ このレポートでは検出できず、音響測定(F0 抽出)か聴取が必要
- 期待値を記入する際は「その語を単独で読んだときの自然な型」を基準にする(文脈依存の型は文単位で登録する)

## 既知の欠陥:1,200 の セ/ン(2026-09-14、native speaker のアノテーションで確定)

native speaker の知見:**`1,200` の H/L は `HHLHH`(前置きあり)または `LLLHH`(文頭)で、いずれの場合も「セン」の 2 モーラは同じトーンになる**(手前に文章があるかどうかで HH か LL が変わる)。

現状の素性は **`HLLHH`** — セ=H なのに ン=L で、**どちらの許容形にも反する**。整列表示で確認:

```
[NG] 1,200 | カナ センニヒャク | tones HLLHH | expected LLLHH
            セH ンL ニL ヒャH クH
```

- 末尾(ニL ヒャH クH)は両許容形と一致しているので、欠陥は**セ/ンの 2 モーラに限定**される
- 文脈依存も同様にずれている(「ご注文は1,200円です」でも セ=H, ン=L)
- **原因の候補**:撥音(ン)・促音(ッ)・長音(ー)は**特殊拍**でアクセント核にならないため、直前のモーラと同じトーンになるべきだが、現行の素性生成はその規則を課していない。`[`/`]`(アクセント句の高低ステップ)が セ と ン の間に入っている疑い
- **文頭が H で始まる点**も第二の論点:文頭(前置きなし)は `LLLHH` なので、句頭が H になっている

### 次の一手(アクセント)

1. **特殊拍のトーン継承**を規則として入れる(直前のモーラと同じトーンにする)→ `HLLHH` は `HHLHH` になるはず(前置きありの形と一致)
2. 残る**句頭の高低**(文頭 vs 文中)を調べる — ここが合えば `LLLHH` も出る
3. 上記は素性側の修正。**実現側(F0)の確認**も並行して価値がある(素性が正しくなった後、実際に音が上がっているか)
- 期待値の記入後、`cargo run --release --features onnx --example accent_report` が不一致で非ゼロ終了するので、CI の gate に組み込める

## 次の一手

- native speaker(あなた)が `expected_tones` を埋める → 一致チェックが gate 化
- 1,200 については **F0 を実測**して素性(H/L)と比較する:素性どおりに上がっていれば「読みは正しく、聞こえの問題」、上がっていなければ「実現側の欠陥」と切り分けられる

## 素性表現の限界(2026-09-14、追加所見)

listener が「先週と比べると」の自然形を **`HHHMLMMMMM`**(M = 中程度の高さ)と記述した。しかし **現行の素性はモーラごとの H/L 2 値**(VITS2 decode に渡るアクセント素性)であり、**M のような中間レベルは表現できない**。

- 含意 1:素性が正しくても、自然な日本語の緩やかな F0 変化は**モデルの実現側**が担う。したがって素性の一致は音の自然さの必要条件であって十分条件ではない
- 含意 2:このレポートで `ok` になった項目でも、聴感上の不自然さが残る可能性がある。最終判定は聴取(F0 実測を併用)
- 運用:アノテーションは H/L に丸めて記入し、M の情報は `note` に残す(上記の例のように)

## 研究調査(2026-09-14): 数詞のアクセントは「複合語アクセント規則」の問題

listener の指摘「**千円は セH ンL で正しいが、千二百円ではそうならない**」は、数詞を含む複合語のアクセントという既知の研究領域に一致する。調査結果:

### 1. 左優勢(left-dominant)アクセント — 記憶されていた研究はこれ

[**Left-dominant Accentuation: The Case of Sino-Japanese Numeral Compounds**](https://doi.org/10.15083/00016465)(東京大学学術機関リポジトリ)

- 従来の複合語アクセント論は「**右優勢**(後部要素 N2 がアクセントを決める)」が主流(Kubozono 1997, Tanaka 2004 ほか)
- しかし**数詞を前部要素(N1)に持つ複合語はこの規則で説明できない**。数詞の場合、**N1 のアクセントが保持される**(=左優勢)と主張する論文
- 例:熟語(アクセントなし)になるはずの「一語」が「イチ＼ゴ」とアクセントを持つ、など
- **重要な制約**:「**非母音モーラ(特殊拍)はアクセント核になれない**」(PK-PROM)。アクセント核が促音化したモーラに来る場合は核が移動する

→ **千円 = セH ンL はこの制約と整合**(核が セ にあり、特殊拍の ン は核になれないので後ろに下がる=H L)。つまり**我々のトーン生成は千円については正しく、欠陥はアクセント推定側**という診断を裏付ける

### 2. 一般の複合語アクセント規則(後部要素の長さで決まる)

[**日本語複合語のアクセント付与規則**](http://hdl.handle.net/2115/45656)(北海道大学)

- 後部要素が **5 拍以上**:前部要素は平板化し、後部要素の元のアクセントを保持
- 後部要素が **3〜4 拍**:前部要素は平板化し、**後部要素の第 1 拍に核**
- 後部要素が **1〜2 拍**:別規則(窪薗・山本 1999 の a/b/c)

→ 「千二百」= セン(2 拍)+ ニヒャク(3 拍)では「**前部 セン が平板化**」する側の規則が働く。listener の期待(セ ン が同一トーン)と方向が一致する

[**Kubozono & Mester, Japanese compound accent (foot-based)**](https://people.ucsc.edu/~mester/papers/1995_kubozono_mester_japanese_compound_accent.pdf) はこれを韻脚(foot)単位で一般化:1〜2 韻脚の後部要素では「**penultimate foot に複合アクセント**」、3 韻脚(overlong)では後部要素のアクセントが保持される

### 3. 実務の権威: NHK の扱い

[**「数詞＋助数詞」の発音とアクセント**](https://www.nhk.or.jp/bunken/research/kotoba/pdf/20160901_5.pdf)(NHK 放送文化研究所)

- 数詞+「円」のアクセントは伝統的に不規則(1/2/3/6/8 円=平板、4/5/9 円=頭高、7 円=中高)
- 『NHK日本語発音アクセント新辞典』(2016)は**「円」の前で落ちる型へ単純化**する方向を採り、平板型を第 2 アクセントとして併記
- 数詞+助数詞の読み(4=ヨ/ヨン、7=ナナ)とアクセントを 258 助数詞について整理した研究もある([KCI 2021](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002793674))

### 4. TTS 側の最先端

[**Phonetic and Prosodic Information Estimation from Texts for Genuine Japanese End-to-End TTS**](https://www.isca-archive.org/interspeech_2021/kakegawa21_interspeech.pdf)(Interspeech 2021)

- 日本語 TTS の最大の難所は「**アクセント核を適切な位置に置くこと**」であり、従来は規則・辞書依存
- 文字単位の NMT(Transformer)で音素・プロソディを推定し、**手作業アノテーション 5,142 文で PPI 95.0% 精度**
- つまり「辞書・規則では数詞のような文脈依存ケースを捉えきれない」という我々の問題意識は研究でも共有されており、**ニューラル PPI 推定が長期的な解**

## この調査を踏まえた修正方針(改訂)

| 案 | 内容 | コスト | 位置づけ |
|---|---|---|---|
| **A. アクセント上書き表**(ユーザ所有) | 「センニヒャク」→ 平板 等を指定。用語辞書と同じ「ユーザが語彙を持つ」思想 | 小 | **まずこれ**。観測済みケースを即修正でき、検証器(accent_report)も既にある |
| **B. 数詞複合語のアクセント規則** | 左優勢+後部要素長の規則を実装し、数詞+助数詞のアクセントを自動推定 | 中 | A の後。**規則ごとに A/B と聴取で検証**が必要(規則は方言・世代差あり) |
| **C. ニューラル PPI 推定** | NMT でアクセント核を推定(研究水準) | 大 | 長期。モデル・学習データ・ONNX 化が必要 |

**現時点の結論**:我々のトーン生成は「特殊拍は核になれない」制約を含め**千円では正しい**。欠陥は**数詞複合語のアクセント推定**にあり、まず **A(上書き表)** で実害を止め、**B** を研究知見(左優勢・後部要素長)に沿って段階的に実装し、各段階を聴取で検証するのが妥当。

## 追記(2026-09-14): 「二千二百円」は文献で扱われている

listener の指摘「千円・二千円は セH ンL だが、千二百円ではそうならない」に続き、**「二千二百円」のようなケース**を一次資料で確認した。結論: **記述は存在し、しかも我々の欠陥そのものを説明する規則が 3 つある**。

### 規則 1: 千を含む短い複合語は「penultimate アクセント」

[Wikipedia: Japanese pitch accent rules (numerals and counters)](https://en.wikipedia.org/wiki/Japanese_pitch_accent_rules_(numerals_and_counters)) の *Numeral + sen* 節:

> Short compounds with ''sen'' [/séN/] are **all penultimate-accented**

例: `/iQ-séN, haQ-séN, ɾokɯ̥-séN, …, **ni-séN**, …, **saN-zéN**/`

- **千 = /séN/**(セに核)→ listener の「千円は セH ンL」と一致
- **二千 = /ni-séN/**(やはりセに核。二は核を持たない)→ listener の「二千円も セH ンL」と一致
- つまり**裸の千/二千ではアクセントは セン に残る**。ここまでは我々の実装も正しい

### 規則 2: 「‑sen 以上の数詞 + 数詞」は**分離可能な小句**(separable minor phrase)として結合する

同記事の *‑sen or larger number + number* 節:

> ''‑sen'' and larger numbers normally combine with other numbers as **separable minor phrase**

例: `/séN ɡo-hjakɯ ~ séN | ɡo-hjakɯ́/`(千五百 = 一息で読むか、**セン|ゴヒャク と小句に分かれる**)

さらに:

> In some contexts such as sport, it is not impossible for **the first component to lose its nucleus**: `/seN ɡo-hjakɯ́/`

- つまり「千 + 数詞」では、**前部(セン)が核を失う/平板化する**ことが明記されている。listener の「千二百円では セH ンL にならない」はこの規則の記述そのもの
- **二千二百**はこの規則の適用例になる:二千(/ni-séN/, セに核)+ 二百(/ni-hjakɯ́/, **クに核**)= **2 つのアクセントを持つ**ので、`ニセ＼ン | ニヒャ＼ク` のように**小句 2 つ**として実現されうる。裸の千二百(前部=千)とはここが異なる

### 規則 3: 助数詞「円」はアクセントを「円の前」に引き寄せる

[NHK 放送文化研究所「数詞＋助数詞」の発音とアクセント](https://www.nhk.or.jp/bunken/research/kotoba/pdf/20160901_5.pdf):

- 『NHK日本語発音アクセント新辞典』(2016)は「数詞＋円」を **［○○＼エン］(円の前で落ちる型)** へ単純化する方向を採用し、平板型は第 2 アクセントとして併記
- 例: 「1円」の調査で［イチ＼エン］支持が 6 割を超えた

→ **数詞＋円**では、数詞内部のアクセントが**助数詞の支配する型に上書きされる**。これが「千二百円」で セン が セH ンL にならない主要因と考えられる

### 我々の実装への含意

- **裸の数詞(千円・二千円)は現状で正しい**。欠陥は「**数詞 + 数詞**」および「**数詞 + 助数詞**」の結合規則に限定される(診断と一致)
- 規則 B を実装するなら、必要なのは次の 3 つ:
  1. **-sen 複合語は penultimate アクセント**(千系: 二千=ニセ＼ン)
  2. **-sen 以上 + 数詞 は分離可能な小句**(小句境界=トーンリセットとして表現可能。我々の `#` 境界がこれに相当)
  3. **数詞 + 円 は「円の前で落ちる」型**(助数詞側が支配)
- いずれも**複数アクセント・小句境界**を扱う必要があり、単純な語単位の上書き表(A 案)では表現しきれない。ただし**A 案で実害は止められる**ため、A → B(この 3 規則を順に、聴取で検証)の順で進めるのが妥当

### 検証のしかた

- 「二千二百」「千二百」「千百」等を accent_report の対象に追加し、実装後の素性を文献の予測(`ニセ＼ン | ニヒャ＼ク` 等)と比べる
- 最終判断は聴取(素性は H/L 2 値なので、M 相当の緩やかな実現は測れない)

## 追記2(2026-09-14): listener の実発音(3 核)と文献の対応

listener の「二千二百円」の実発音をモーラに展開すると:

```
ニH セH ンL | ニL ヒャH クH | エH ンL     (8 モーラ、H/L 列 = H H L L H H H L)
```

これは **核が 3 つ**(二千の セ、二百の ク、円の エ)であり、文献と照合した結果:

### (1) 「1 アクセント句 = 最大 1 核」+「有核語間で境界を挿入」→ 3 核は構造的に正しい

[**Accentual Phrasing in Japanese: The Significance of Underlying Accents**](https://www.isca-archive.org/speechprosody_2002/miyamoto02_speechprosody.pdf)(Miyamoto, Speech Prosody 2002)

- アクセント句(accentual phrase)は **最大 1 つのアクセントしか含まない**ことが広く合意されている
- 実験の結論:**「2 語のうち少なくとも一方が基底で有核なら、その間にアクセント句境界が挿入される」**
- → 二千(セに核)・二百(クに核)・円(エに核)は**それぞれ有核**なので境界が入り、**3 つのアクセント句**になる。listener の 3 核はこの規則の予測どおり

### (2) 句頭の上昇(initial lowering)とその抑制 → ニH の説明候補

[**Diphthongs in Tokyo Japanese: Evidence from Initial H-leveling**](https://www.jstage.jst.go.jp/article/kyoyobukiyo/2020/50/2020_31/_pdf/-char/en)(J-Stage)

- 東京方言では**句頭でピッチが上昇する**(=第 1 モーラが低く始まる。initial lowering / initial rise)
- ただし**必ず起こるわけではなく、抑制される条件**が 2 つ挙げられている:
  1. **語頭モーラにアクセントがある**とき(句が高いピッチで始まる)
  2. **句頭音節が重音節**(促音・撥音・長音・二重母音を含む)のとき
- さらに [**Degree of Initial Lowering in Japanese as a Reflex of Prosodic Structure Organization**](http://citeseerx.ist.psu.edu/viewdoc/summary?doi=10.1.1.222.6767) は、**句頭の上昇は major phrase(XP)境界でより大きく、minor phrase 境界では有意に小さい**ことを示した
- → listener の **ニH**(低く始まらない)は、**1 つの major phrase 内部の minor phrase 列**として実現しているため句頭の下降が弱まっている、という説明が立ちうる。**解剖学的な要因より韻律構造の要因で説明できる**

### (3) 数詞+助数詞のアクセントは「揺れ」が文献に明記されている

[**NHK「数詞＋助数詞」の発音とアクセント**](https://www.nhk.or.jp/bunken/research/kotoba/pdf/20160901_5.pdf)

- 「1 円」の調査で**平板型 89% / ［イチ＼エン］60%**(併記)、「30 円」は**中高型 85% / 頭高型 8%**、「30 日」で中高 98% — **支持率つきで複数の型が併記**されている
- **職種による差**の実例: ANA の客室乗務員は「1 便」を便名=平板/便数=起伏と読み分けるが、**地上アナウンス担当者はどちらも起伏**だった
- 若年層を中心に**単純化・規則化**が進行中(秋永ほか 1999 など)
- → **個人差・世代差・職種差は文献が明示的に認めている**領域。listener の実発音が辞書の第一形と違っても異常ではない

### 結論(実装への意味)

1. **listener の 3 核パターンは文献の構造規則(1 句 1 核+有核間境界)と整合**する。固有の「口腔構造」由来と考えるより、**韻律構造と揺れの範囲内**と見るのが自然
2. musculus にとって重要なのは「**正解が一つでない**」こと。したがって:
   - **A(アクセント上書き表)は“ハック”ではなく正しい設計**: どの型を選ぶかはユーザ(話者)が持つ
   - **B(規則)は辞書第一形に寄せる既定**として実装し、揺れは A で吸収する
3. **検査可能な不変条件が 1 つ増えた**: 「**1 アクセント句に核は最大 1 つ**」は機械的に検査できる。アクセント層の実装時にテスト/A/B 前チェックとして使う
4. 円の実現にも型の選択がある: 伝統的な **エン[1](エH ンL)** / 2016 の単純化 **［○○＼エン］**。listener は前者を採っている
