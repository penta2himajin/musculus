# 聴き比べ:複合語アクセント規則(NHK の N2 拍数分類)の検証

**同じ語・同じ声・同じ音量**で、**アクセントだけ**が違う 2 テイクです。どちらが自然かを判定して、規則層を既定にするかどうかを決めます。

## 何を検証しているか

文献(NHK 放送文化研究所の改訂記録 + 窪薗・山本 1999)は、複合名詞のアクセントを**後部要素(N2)の拍数**で次のように予測します:

| N2 | 型 | 核の位置 |
|---|---|---|
| ≤2 拍 | 前部末型 | N1 の最終拍 |
| 3〜4 拍 | 後部一型 | N2 の第1拍(N2 が頭高/平板・尾高のとき) |
| ≥5 拍 | 後部保存型 | N2 のアクセントを保持(N2 が平板なら全体平板) |

これを `src/compound.rs` に実装しました。**10 語で現在の出力が変わる**ため、その 10 語を聴き比べます。

## 対象語(10 ペア)

| ペア | 語 | | ペア | 語 |
|---|---|---|---|---|
| 01 | 生成的人工知能 | | 06 | 地球温暖化 |
| 02 | 大規模言語モデル | | 07 | 感染症対策 |
| 03 | 自然言語処理 | | 08 | 働き方改革 |
| 04 | 再生可能エネルギー | | 09 | 少子高齢化 |
| 05 | 個人情報保護 | | 10 | 地域活性化 |

※ 05 と 06 は**あなたが既に期待形を確定した語**です(上書き表に登録済み)。規則を単独で使った場合に同じ形になるかを見るために対象に含めています — 規則 on の音は登録形を上書きしない設定なので、その2語は「規則だけでは合うか」の確認になります。

## 聴き方

1. 各ペアで `A.wav` → `B.wav` を聴く(順序を変えて2回)
2. [score-sheet.md](score-sheet.md) に記入:好ましい方・CMOS(−3〜+3)・気づいた点
3. 対応表(どちらが規則か)は採点後に開示します

## 判定の意味

- **規則側が優勢** → 規則層を既定に昇格(未知の複合語が自動で正しくなる)
- **語によって違う** → 規則は「提案」として残し、上書き表で確定する運用
- **現在側が優勢** → 規則層は不採用(文献の規則が我々の辞書・実装と噛み合わないと判断)
