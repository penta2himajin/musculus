# 盲検 A/B:文分割 + 文間無音の効果(SBV2)

**「息切れ」仮説の検証**です。listening-log 第 5 回で SBV2 側に観測された「息が切れたような発声」(5 サンプル中 2)について、参照実装が長文を**文単位に分割して無音を挟む**のに対し、musculus の CLI は入力を**1 パスで**合成していた点を疑い、両者をブラインドで並べました。

## ファイル構成

```
listening/03-sbv2-whole-vs-split/
  pair-01/A.wav  B.wav   ← 同じ文・同じエンジン。片方は 1 パス、片方は文分割 + 0.4 秒無音
  ...(全 5 ペア)
  key.ndjson             ← どちらが分割版か(採点まで開かない)
  score-sheet.md
```

## 比較条件

- **同一エンジン(SBV2JE / tsukuyomi)、同一テキスト**。違いは「1 パス」か「文分割 + 0.4 秒無音」のみ
- 両側とも 48 kHz モノラル、**−20 LUFS に一致**(全 5 ペアで達成値 −20.00 を検証済み)
- 分割側は挿入した無音の分だけ**音声が長くなります**(例:2 文で +0.4 秒)— これは介入そのものなので評価対象です

## 聴き方

1. ペアごとに A → B(順序を変えて 2 回聴くと確かです)
2. 特に聴くところ:
   - **息継ぎの自然さ**、文の切れ目で声が続きすぎていないか(これが本命)
   - 文頭の立ち上がり・文末の収まり
   - 分割側の**無音が長すぎ/短すぎ**ないか(0.4 秒固定なので調整余地があります)
   - 抑揚が文ごとにリセットされることで**不自然に感じないか**
3. 判定:どちらが自然か、差の大きさ(CMOS −3〜+3)、気づいた点

## 判定の意味

- **分割側が良い/特に息切れが減った** → CLI の既定を文分割にし、無音長を調整する(実装済みの `--split-sentences` / `--sentence-silence`)
- **差がない/1 パスが良い** → 「息切れ」は文分割では説明できず、別要因(モデル・スタイル・sdp_ratio)を当たる
- どちらでも、`1 パス vs 分割` の選択が**測って決まる**状態になります
