# 盲検 A/B:低ステップ品質の検証(同一エンジン・steps 5 vs 40)

Irodori-TTS の**Euler steps だけを変えた**2つの音声を、どちらがどちらか伏せて並べたセットです。ADR-0005 が残した「5 steps の音は 40 steps と同等に自然か」を耳で判定するためのものです。

## ファイル構成

```
listening/02-irodori-steps/
  pair-01/A.wav  B.wav      ← 同じ文・同じ seed、steps だけが違う(A/B はペアごとにランダム)
  pair-02/A.wav  B.wav
  pair-03/A.wav  B.wav
  pair-04/A.wav  B.wav
  pair-05/A.wav  B.wav
  key.ndjson                ← steps の対応表(採点が終わるまで開かない)
  score-sheet.md            ← 採点用紙
```

## 比較条件(重要)

- **同一エンジン・同一 seed・同一テキスト**。違いは rectified-flow の Euler steps のみ
- **統合ラウドネスを一致**:両側とも 48 kHz モノラル・**−20 LUFS** に正規化し、**ペアごとに達成値が ±0.3 LUFS 以内であることを検証**してから提示しています

### なぜ −20 LUFS なのか(測定で見つけた落とし穴)

最初は −16 LUFS で作ったのですが、**低ステップ出力はピーキーなためピークリミッタが作動し、目標に届かないまま 2 つの音が約 3.6 dB ずれました**(RMS 0.14 vs 0.09)。これは「大きい方が良く聞こえる」バイアスをそのまま持ち込むので、ターゲットを −20 LUFS に下げて両側とも制限なしで目標に到達させ、さらに**提示前の検証を自動化**しました。以降の A/B は必ずこの検証を通します(`scripts/make_ab_test_steps.sh`)。

残る RMS 差(数 dB)は、低ステップ出力がトランジェント豊かで K 加重ラウドネスあたりの RMS が低いためで、**ラウドネスは一致しています**(知覚的な大きさは揃っています)。

## 聴き方

1. ヘッドホンで、ペアごとに A → B(順序を変えて2回聴くと確かです)
2. 特に聴くところ:
   - **ざらつき・金属的なノイズ・息の混入**(拡散ステップ不足で出やすい)
   - **語尾や子音の潰れ**、息継ぎの不自然さ
   - **抑揚の滑らかさ**(ステップ不足で平板・不安定になりやすい)
3. 判定:どちらが自然か、差の大きさ(CMOS −3〜+3)、気づいた点

## 判定の意味

- **差が小さい/同等** → Irodori 5 steps を既定の高速モードにでき、**実時間(RTF 0.83)と品質を単一エンジンで両立**できます(二本立てを畳む判断材料)
- **明確に 40 steps が良い** → 高速モードは 40 steps の代用にならず、二本立て(SBV2=即応、Irodori=品質)を維持する根拠が残ります

採点後に `key.ndjson` を開いて集計し、listening-log と ADR に記録します。
