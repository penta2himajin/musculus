# 採点シート:sdp_ratio(テンポの緩急)

同じ声・同じ音量で、**duration 予測の混合比だけ**が違います。どちらが 0.2 かは伏せてあります。

| ペア | テキスト | 好ましい方 (A/B/同等) | CMOS (−3〜+3) | 気づいた点(テンポ・間の取り方・不自然さ) |
|---|---|---|---|---|
| 01 | その森には、古い言い伝えがありました。… |  |  |  |
| 02 | 現在の時刻およびドル円の為替を… |  |  |  |
| 03 | こんにちは。今日はとても良い天気ですね。 |  |  |  |
| 04 | 会議の資料を確認しました。… |  |  |  |
| 05 | 昨日は雨でしたが、今日は晴れました。… |  |  |  |

## 全体所感

- 一貫して良いと感じた側はあったか:
- **間の取り方**(文節間の休止、語の伸ばし方)に違いを感じたか:
- 一定すぎる/揺らぎすぎると感じた側はあるか:
- 短文と長文で評価が変わったか:
- 「息切れ」や「機械的」といった印象はどちらに感じたか:
