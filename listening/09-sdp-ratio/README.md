# 聴き比べ:SBV2 の sdp_ratio(テンポの緩急)

**同じ声・同じ音量**で、**duration 予測の混合比だけ**が違う 2 テイクです。どちらが自然かを判定して、既定値を決めます。

## 何を比べているか

Style-Bert-VITS2 の `sdp_ratio` は **DP(決定的 duration 予測)と SDP(確率的 duration 予測)の混合比**です。

| 設定 | 意味 | 実測(長文 3 回) |
|---|---|---|
| **0.0**(我々の既定 = Rust 参照) | DP のみ = **毎回同じ長さ** | 10.04 / 10.04 / 10.04 秒 |
| **0.2**(上流 Python の既定) | SDP を 2 割混ぜる = **テンポに緩急** | 9.68 / 9.73 / 9.76 秒 |

つまり違いは「**機械的に一定のテンポ**」か「**揺らぎのあるテンポ**」かです。上流の説明は「値を大きくするとテンポに緩急がつく」。

## 対象(5 ペア)

| ペア | テキスト(冒頭) |
|---|---|
| 01 | その森には、古い言い伝えがありました。… |
| 02 | 現在の時刻およびドル円の為替を… |
| 03 | こんにちは。今日はとても良い天気ですね。 |
| 04 | 会議の資料を確認しました。… |
| 05 | 昨日は雨でしたが、今日は晴れました。… |

長さが違う文を混ぜてあります(緩急の効果は長い文で出やすいため)。

## 聴き方

1. 各ペアで A → B を聴く(順序を変えて 2 回)
2. [score-sheet.md](score-sheet.md) に記入
3. 対応表(どちらが 0.2 か)は採点後に開示

## 判定の意味

- **0.2 側が良い** → 上流既定を採用し、既定値を変更(`--sdp-ratio` は実装済み → 定数化してゲート)
- **0.0 側が良い** → Rust 参照の既定を維持(安定性を優先)
- **文の長さで違う** → 長文のみ 0.2 にする、などの条件付き運用

なお `noise_scale`(我々 0.677 / 上流 0.6)も未測定の候補です。sdp_ratio が決まった後に続けて検証できます。
