# 盲検 A/B(エンジン品質比較)

2つの日本語 TTS エンジン(以下 E1 / E2)を、**同一テキスト・同一参照音声**で合成した聴取セットです。どちらがどちらかは伏せてあります。

## ファイル構成

```
listening/01-engine-vs-engine/
  pair-01/A.wav  B.wav      ← 同じ文を2エンジンで合成(A/B はペアごとにランダム)
  pair-02/A.wav  B.wav
  pair-03/A.wav  B.wav
  pair-04/A.wav  B.wav
  pair-05/A.wav  B.wav
  key.ndjson                ← エンジンの対応表(採点が終わるまで開かない)
  score-sheet.md            ← 採点用紙
```

## 比較条件(重要)

- **同一テキスト**:各ペアの A と B は同じ文。数字・日付・記号を含む文もあります(各エンジンの正規化処理も込みの比較)
- **同一参照音声**:両エンジンとも同じ話者の参照音声を使っています(声の好みを品質判断から分離)
- **コンテナと音量を統一**:両側とも 48 kHz モノラル・**−16 LUFS** に正規化済み(ピーク制限込み)。これがないと「44.1 vs 48 kHz」というファイル形式や音量差でエンジンが分かってしまい、判断が歪みます
- 長さの違い(例:pair-01 は 4.3 秒 vs 3.1 秒)は各エンジンの話速・間の取り方の差そのものです

## 聴き方

1. ヘッドホン/スピーカーで、ペアごとに A → B の順に聴く(順序を変えて2回聴くと確かです)
2. 各ペアについて「どちらが自然か」「差の大きさ」を [score-sheet.md](score-sheet.md) に記録
3. **採点が終わるまで `key.ndjson` を開かないでください**(開くと盲検が壊れます)

## 採点の目安

| 観点 | 見るところ |
|---|---|
| 自然さ | 抑揚・アクセント、間の取り方、息継ぎの自然さ |
| 明瞭さ | 読みの正確さ(数字・日付・助詞)、聞き取りやすさ |
| 声質 | 参照音声への似方、質感、こもり・ノイズ |
| 破綻 | 不自然な伸び・詰まり・ノイズ・尻切れ |

CMOS は −3〜+3 で:
`+3` A が圧倒的に良い / `+1` A がやや良い / `0` 同等 / `-1` B がやや良い / `-3` B が圧倒的に良い

採点が終わったら教えてください。`key.ndjson` を開いて集計し、結果を listening-log と ADR に記録します(必要なら A/B を入れ替えた再テストも可能です)。
