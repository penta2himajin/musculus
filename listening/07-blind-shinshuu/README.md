# 聴覚評価のお願い:「先週と比べると」の 6 テイク

同じ声・同じ文を 6 通りに読み分けた音声です。**どれが「正解」ということはなく、自然に聞こえるかを知りたい**ので、直感で構いません。

## 使い方

1. `A.wav` 〜 `F.wav` を順に聴いてください(ヘッドホン推奨)
2. 各テイクの**自然さを 5 段階**で採点してください(5 = とても自然 / 1 = 不自然)
3. そのうえで「**いちばん自然だと思うもの**」を 1 つ選んでください
4. 気づいた点があれば自由に書いてください(例:息継ぎが不自然、語尾が下がりすぎ、平坦すぎる、など)

採点は [score-sheet.md](score-sheet.md) に記入してください。

## 条件

- **すべて同じ文・同じ声・同じ話速**で、違いは**ピッチ(アクセント)の付け方だけ**です
- 音量は全テイクでそろえてあります(−20 LUFS)。**大きい方が良く聞こえる**ということはありません
- 順序はランダムなので、A が基準といった前提はありません
- 2 回ずつ、順番を変えて聴くと判断が安定します

## 送っていただくもの

- 記入済みの `score-sheet.md`(または本文に貼り付け)
- 迷ったテイクがあればその旨

集計後、どの形が支持されたかをフィードバックします(どのラベルがどの音調だったかは、採点が終わってから開示します)。
